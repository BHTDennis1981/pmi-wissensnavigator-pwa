# PMI Wissensnavigator – App-Shell (ohne Wissensdaten)

Installierbare Mobile-First-PWA mit Offline-Caching für die App-Oberfläche. FAQ- und Graphdaten müssen nach dem Öffnen lokal importiert werden. Dieses Repository enthält bewusst keine interne Wissensdatenbank.

Für die Installation die GitHub Pages-URL aufrufen und die App über das Browsermenü installieren. Danach eine vollständige Viewer-Datenpaket-JSON importieren. Dieser lokale Datenbestand wird im Browser auf dem Gerät gehalten und sollte regelmäßig als JSON exportiert werden.
